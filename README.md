# SunProof — verifiable solar RECs (IEEE ClimateChain 2026, Track 2)
Static web app: hourly solar meter readings → anomaly audit (night output, over-capacity, z-score) → SHA-256 Merkle root → 1-MWh REC issuance memo suitable for an on-chain anchor (e.g. Solana Memo) → tamper detection.
Demo data is synthetic. Run: open `index.html`. By Solar DePIN Hub (Ukraine).
